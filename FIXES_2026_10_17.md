# EL BEM BEAUTY 2.0 — целевые исправления

## Сделано в этой версии
- Исправлена регрессия CSS: плавающие WhatsApp и музыка зафиксированы справа внизу окна, независимо от прокрутки.
- Сохранены прежние страницы и фоновые лепестки.
- Контент главной, разделов «О нас» и обучения поддерживает значения RU/KG/EN через вкладки в админке.
- Добавлены языковые поля для названий, описаний услуг, товаров, мастеров и категорий. Для данных каталога подготовлена миграция `supabase/008_localized_catalog.sql`.
- Адрес и график работы также редактируются отдельно на RU/KG/EN.
- Для демонстрационных текстов добавлены словарные переводы.

## Важно при установке
1. Архив заменяет исходники предыдущей версии; базу автоматически не изменяет.
2. Если Supabase подключён и миграции 001–007 уже были применены на **отдельной чистой базе EL BEM 2.0**, выполнить **только** `008_localized_catalog.sql`. Не выполнять повторно 001–007.
3. В админке заполнить KG и EN для собственных заголовков, описаний и адреса, затем нажать «Сохранить изменения» или «Сохранить настройки». Машинного автоперевода произвольного нового текста нет.
4. Запустить `npm install && npm run build && npm run dev`.

## Не подтверждено в этой среде
- Полноценная npm-сборка: офлайн npm-cache не содержит Supabase SDK.
- Живые Supabase Auth, Storage, бронирования и RLS, Realtime, email/Telegram: требуют подключения аккаунтов и испытаний в действующей среде.
- Полное покрытие интерфейса переводами: часть второстепенных/администраторских надписей ещё задана как русские литералы.

Версия является исправлением интерфейса и локализации, а не проверенным коммерческим релизом.
