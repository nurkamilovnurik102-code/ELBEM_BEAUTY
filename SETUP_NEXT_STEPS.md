# Простой порядок запуска и проверки

1. Откройте папку в VS Code. Установите Node 20+. Выполните `npm install`, затем `npm run build` и `npm run dev`.
2. Проверьте деморежим без `.env`: гостевая запись хранится **только в браузере**. Админка без Supabase — демонстрационная, не защищённая.
3. Для настоящей БД создайте отдельный чистый Supabase проект. Не применяйте `001_initial.sql` к старой базе без аудита. На пустом проекте последовательно выполните `001_initial.sql`, `002_media_storage.sql`, `003_media_audio_realtime.sql`, `005_booking_schedule.sql`, опционально `004_demo_seed.sql` только на чистой базе, затем `006_catalog_categories.sql` и `007_client_accounts.sql`.
4. `.env.example` скопируйте в `.env` и вставьте только публичные VITE_SUPABASE_URL и VITE_SUPABASE_ANON_KEY (publishable/anon). Не вставляйте service role key в Vite.
5. Создайте в Supabase Auth пользователя владельца. После подтверждения email выполните через защищённый SQL Editor `insert into public.admin_users(user_id) values ('<UUID владельца>') on conflict do nothing;`.
6. Укажите в админке адрес, WhatsApp, загрузите лицензированные изображения, музыку. Файлы должны быть JPG/PNG/WebP (до 5 МБ) и поддерживаемые аудио (до 20 МБ).
9. Перед настоящим запуском доведите серверную проверку расписания, антиспам, безопасные роли, тексты согласия и полную локализацию, затем выполните E2E-проверки бронирования и заказов.
10. Для переноса владельцу: разверните базу под его организацией Supabase, замените демонстрационные записи, настройте домен, права, бэкапы и коммерческий хостинг.


После SQL 005 в админке доступен редактор рабочих дней мастера. После изменения сохраните график, затем перепроверьте доступность времён на клиентском сайте.
Для экрана KG/RU/EN статические тексты заданы в `src/i18n/*.json`; динамические имена товаров, услуг и тексты администратора пока не переводятся автоматически.

Клиент может открыть «Кабинет» через значок пользователя в шапке. Авторизация необязательна для гостевой записи; аккаунт позволяет видеть только заявки, созданные во время входа в этот аккаунт.

**Актуальная схема:** нет email-уведомлений и Telegram-бота. Записи сохраняются в Supabase, в админке кнопка «Telegram» копирует заявку и открывает выбранный владельцем @username для ручной отправки. Начните с `SUPABASE_START_HERE.md`.
