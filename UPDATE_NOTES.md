# EL BEM BEAUTY 2.0 — targeted UI update

## Изменения
- Страницы «Подробнее» для товара, услуги и мастера; открываются нажатием на фото или название. Товары — кнопка «В корзину», услуги/мастера — «Записаться».
- Адаптивная галерея изображений в карточках: `object-fit: cover`, фиксированные пропорции, обрезка без растяжения.
- В админских формах услуг, товаров, мастеров, отзывов и изображений главной/обучения — выбор JPEG/PNG/WebP файла, URL и предпросмотр. В Supabase-режиме файл загружается в `site-media`; в деморежиме используется base64 внутри localStorage, **только для небольших тестовых файлов**.
- Отдельная SQL-миграция `supabase/002_media_storage.sql` для Storage bucket и RLS policies (запись только администратору).

## Ограничения и незавершённые функции
- Новые **подробные страницы реализованы как клиентские виды**, а не SEO-маршруты с URL. Для SEO и прямых ссылок потребуется React Router и отдельные пути.
- В деморежиме localStorage ограничен по размеру. Для реальных фотографий **обязательно** подключить Supabase Storage.
- Новая миграция выполняется **только после** проверки существующих Storage policies на выбранном Supabase проекте. Если аналогичные политики существуют, SQL нужно согласовать во избежание дубликатов.
- Нет полноценного медиаменеджера с повторным выбором ранее загруженных файлов, отдельного кадрирования через drag, автоматической конвертации изображений, серверной обработки доступности бронирований, завершённого i18next, email, Telegram или Realtime. Это **не готовая коммерческая версия**.
- Сборка `npm run build` **не проверена** из-за таймаута установки зависимостей в среде; синтаксис TSX проверен парсером TypeScript без ошибок. Тесты на реальной Supabase базе не запускались.

## Запуск и проверка
1. Распакуйте ZIP, откройте папку в VS Code.
2. `npm install` → `npm run build` → `npm run dev`.
3. Проверьте карточки услуги, мастера и товара, переход на «Подробнее», кнопки заказа/записи, мобильный вид.
4. Для локального демо используйте маленькие изображения: браузерное localStorage быстро заполняется.
5. Для Supabase: применяйте Storage migration только после сверки со схемой, настройте `.env` по `.env.example`, создайте первого admin безопасно (не в frontend).
6. Перед реальными клиентами завершить серверную запись, безопасность, вход владельца, переводы, уведомления и end-to-end тесты.
- Дополнительно добавлен раздел фотографий галереи в «Контент сайта»: загрузка нескольких фотографий, миниатюры и удаление из списка, сохранение как `galleryImages` в `site_content`. Изображения из демогалереи используются, пока админ не задаст собственный список.
